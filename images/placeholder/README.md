# Placeholder media

Legg ekte bilder/video her etter hvert som de blir klare. Filnavn koden
allerede refererer til (bytt ut når du har ekte innhold):

- `hero-poster.jpg` — poster-bilde for hero-video (1920x1080 eller større)
- `og-cover.jpg` — delingsbilde for sosiale medier (1200x630)

Se kommentarer i `index.html` og `css/style.css` for nøyaktig hvor disse
brukes.
