# Oldren & Solum Takst — hjemmeside

Hjemmeside for takstfirmaet til Fabian Oldren og Markus Solum.
Ren HTML/CSS/JS, ingen build-steg.

```
index.html     Markup (hero, tjenester, prosess, om oss, FAQ, kontakt)
css/style.css  Stiler (farger/fonter som design-tokens øverst)
js/main.js     Mobilmeny, scroll-animasjoner, kontaktskjema (mailto)
```

Kjør lokalt: `python3 -m http.server 8000` i denne mappen.
