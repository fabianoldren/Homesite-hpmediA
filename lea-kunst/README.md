# Atelier Lea — hjemmeside

Hjemmeside for Leas kunst og malerier. Ren HTML/CSS/JS, ingen build-steg.

```
index.html     Markup
css/style.css  Stiler (farger/design-tokens øverst)
js/works.js    Liste over malerier — legg til nye verk her
js/main.js     3D-karusell, hero-parallakse, tilt, lightbox, scroll-animasjoner
img/           Beskårne bilder av maleriene
```

Kjør lokalt: `python3 -m http.server 8000` i denne mappen.
